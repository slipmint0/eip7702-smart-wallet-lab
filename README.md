EIP-7702 Smart Wallet Lab

About this project

This is a beginner-friendly learning project for understanding Ethereum EIP-7702.

The goal is to learn how an ordinary Ethereum wallet (EOA) can authorize delegation to a smart contract implementation.

Learning objectives

* Understand Ethereum EOAs and smart contracts.
* Understand EIP-7702 authorization.
* Learn Solidity fundamentals.
* Build a safe delegated wallet demonstration.
* Test using Remix and MetaMask on a test network.
* Understand delegation security and revocation.

Development environment

* Solidity
* Remix IDE
* MetaMask
* Ethereum test network

Safety

This project is for education and testing only.

Never use a wallet containing real funds for initial experiments. Never share private keys or recovery phrases.

Project status

Currently learning the fundamentals. No smart-contract code has been written yet.
